这是 UnityX103/Topit 的首个公开预发行版本，基于 lihaoyun6/Topit，沿用 AGPL-3.0 许可证。

- 新增实时区域截取置顶，默认 Command + Shift + T，只有框选部分生成独立浮窗。
- 鼠标操作映射到源窗口；键盘直接使用原输入框，不创建本地转发输入框，不复制草稿或重发键盘事件。
- 按住 Shift 移动、等比缩放及编辑浮窗；支持冻结、复制、透明度调整。
- 双击 Control 开关自动隐藏：鼠标靠近时淡出，移开显示，模式开启期间禁止浮窗交互。
- 修正权限识别、设置窗口生命周期、同应用焦点交接和旧焦点恢复状态等逻辑。
- 增加固定证书签名的增量更新、旧版备份与失败回退；新增 GitHub 双架构测试、通用版本构建及签名发布校验。

下载 `Topit-0.1.22-macOS-universal.zip` 获取完整应用。`Topit-0.1.22.topitupdate` 仅适用于本机同证书签名的 0.1.21/build31；使用仓库 `Scripts/topit_update.py` 先 `apply --check` 再应用。其他版本或官方签名不能直接使用该增量包。

本版本使用固定本地证书，未经 Apple Developer ID 公证。固定身份的常规本地更新旨在保留既有权限，首次安装/签名迁移仍可能需要授权。

已验证 175 项原有检查，并增加发布资产验证测试。自动化未完成 Codex 实体键盘、中文输入法及窗口层级验收；完全遮挡时源应用暂停刷新仍可能影响捕获。后台指针使用 Command 点击语义，部分控件的行为与普通点击不同。窗口焦点能力依赖 macOS 私有接口，兼容性以正式安装版实测为准。
